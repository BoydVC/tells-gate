I built a small tool that reads my draft posts before I approve them. It flags phrases I don't want to use and points at the line.

Setup took about ten minutes. It runs on my own computer, with no account and no network calls. Last week it caught four drafts that opened with a hype word.

The code is about 400 lines of Python. The rule list lives in one markdown file, so I can edit it without touching the code.
